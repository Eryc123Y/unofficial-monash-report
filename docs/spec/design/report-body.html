2Background

A route-planning problem is a graph whose nodes are robot positions and whose edges are single moves with non-negative cost. A search algorithm is optimal if the first path it returns to the goal is a cheapest one. This section fixes the notation used in the rest of the report.

2.1Best-first search

Best-first search keeps a frontier of discovered nodes and always expands the one with the smallest evaluation f(n). A* uses the cost so far plus an estimate of the cost to go [1]:

f(n) = g(n) + h(n). (2.1)

Definition 2.1 (Admissible heuristic). A heuristic h is admissible if h(n) ≤ h*(n) for every node n, where h*(n) is the cost of a cheapest path from n to a goal.

With an admissible heuristic A* is optimal, and a better-informed heuristic expands fewer nodes.1 Figure 2.1 sketches the effect as the map grows.

2.2Admissible and consistent heuristics

Consistency is the stronger condition. It bounds how fast h may fall along an edge, and it lets A* close each node the first time it is expanded.
