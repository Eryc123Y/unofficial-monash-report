# Design mock

Five A4 pages (794 x 1123 CSS px, 1 px = 0.75 pt) exported from the design canvas:
https://claude.ai/artifact/Wj1Yca5HaRCzdy7zMWBR2x

Read the inline `style` attributes for exact sizes, colours and spacing.
The files do not render standalone (they need the canvas runtime), and the
`/_blob/...` image is the logo slot; the package itself ships no logo.
`report-cover.html` shows every optional cover field; its script block lists
which are on by default.
