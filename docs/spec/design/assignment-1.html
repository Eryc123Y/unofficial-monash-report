Question 1

10 marks

Let h be a heuristic on a graph with non-negative edge costs c(n, n′). (a) Show that if h is consistent and h(g) = 0 at every goal g, then h is admissible. (b) Give a heuristic that is admissible but not consistent.

(a)

Write h*(n) for the cost of a cheapest path from n to a goal. Consistency says that the heuristic never drops by more than the cost of the edge just taken:

h(n) ≤ c(n, n′) + h(n′)   for every edge (n, n′). (1)

Lemma 1 (Consistency implies admissibility). If h satisfies (1) and h(g) = 0 at every goal g, then h(n) ≤ h*(n) for every node n.

Proof. Induct on the number k of edges on a cheapest path from n to a goal. If k = 0 then n is a goal and h(n) = 0 = h*(n). Otherwise let n′ be the next node on that path, so that h*(n) = c(n, n′) + h*(n′) and n′ has a cheapest path of k − 1 edges. By (1) and the induction hypothesis,

h(n) ≤ c(n, n′) + h(n′) ≤ c(n, n′) + h*(n′) = h*(n). □
(b)

Take the path s → a → g with both edges of cost 1, and set h(s) = 2, h(a) = 0, h(g) = 0. Every value is at most the true remaining cost, so h is admissible. On the edge (s, a), however, (1) would need 2 ≤ 1 + 0, which is false, so h is not consistent.
