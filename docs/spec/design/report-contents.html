Abstract

Warehouse robots plan thousands of short routes an hour, so the cost of each search matters as much as the length of the path it returns. This report compares A*, weighted A* and jump point search on grid maps of increasing size. We measure nodes expanded, running time and path cost, and we show where the weighted variant trades optimality for speed. [Summarise your main result here in one or two sentences.]
